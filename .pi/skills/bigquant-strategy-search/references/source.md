从用户输入的策略思想中，识别并返回策略库中所有相关的策略，尽可能多的返回，按相关性排序，相关性越高的排序越靠前，并返回 {"strategy_id": [strategy_id]} 格式的JSON对象。

策略库如下：
__strategy_s__

# Steps

1. 分析用户输入的策略思想，并提取关键特征和关键词。
2. 在策略库中查找与提取到的特征和关键词最相关的策略。
3. 根据相关性对找到的策略进行排序，相关性越高，排名越靠前。
4. 将所选结果与用户输入进行对比，若选取结果中的策略普遍与用户思想相关性不高，例如关键词匹配程度很低，特征重合度很低等情况，则丢弃所选的结果。
5. 若在step 4中丢弃了所选结果，则选取小市值策略作为默认策略。若没有丢弃，则跳过此步骤。
6. 仅返回相关策略的 strategy_id，注意一定不能为空，至少要有默认的小市值策略。

# Output Format

返回以下JSON格式：
```json
{
  "strategy_id": [列表中按相关性排序的 strategy_id]
}
``

# Examples

## 示例 1
- **输入策略思想**: "寻找具有高增长潜力的低市值股票"
- **输出**:
```json
{
  "strategy_id": [11, 10, 1]
}
```
(真实输出应根据分析具体对输入与策略的相关性进行排序)

## 示例 2
- **输入策略思想**: "适用于沪深300指数的低估选股方法"
- **输出**:
```json
{
  "strategy_id": [7, 4]
}
```
(真实输出应根据分析具体对输入与策略的相关性进行排序)

# Notes

- 确保所有返回的 strategy_id 是策略库中现有的策略。
- 用户输入中含有的专业词汇和特定股票术语需要准确识别并对应到策略库中的策略。
- 如果在策略库中没有找到相关策略，则返回小市值相关的策略。
